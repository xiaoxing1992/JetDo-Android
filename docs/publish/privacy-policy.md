# JetDo Android 隐私政策

> 生效日期：2026-10-27 ｜ 适用版本：1.0.1 及以上
>
> JetDo Android（以下简称"本应用"）是 LINUX DO 社区（https://linux.do）的**非官方**第三方客户端。我们非常重视你的隐私：本应用**不收集、不上传、不出售任何个人信息**，所有数据仅在你的设备与 LINUX DO 社区之间流转。请在使用前仔细阅读本政策。

## 一、我们收集什么

本应用不内置任何**广告、埋点统计或崩溃上报** SDK，**也不向开发者上传任何数据**。应用联网只为访问 LINUX DO 社区本身。

以下数据由你主动产生，**仅存储在你设备的应用私有目录中**，开发者无法读取：

| 数据 | 用途 | 存储位置 |
|---|---|---|
| 登录会话 Cookie | 维持你在 LINUX DO 的登录态 | 系统 WebView CookieManager（应用私有存储） |
| 本地偏好设置 | 主题、字体、开关项等 | 应用私有目录（DataStore） |
| 帖子草稿 | 未发送的回复/编辑内容 | 应用私有目录 |
| 已读状态、书签缓存 | 离线展示与同步 | 应用私有目录 |
| 图片/表情目录等缓存 | 加速加载、减少流量 | 应用私有缓存目录 |

**卸载应用即全部删除**上述本地数据。本应用**不使用云备份**：已在系统层排除全部应用数据的备份与设备迁移，换机后需重新登录。

## 二、数据流向哪里

本应用联网时，只与以下地址通信：

- **https://linux.do** —— 社区主站：浏览、登录、发帖、回帖、上传图片、实时消息等全部功能的数据来源；
- **https://cdn.ldstatic.com** —— LINUX DO 官方静态资源 CDN：图片、表情等站点资源；
- **https://accounts.hcaptcha.com** —— 人机验证服务，仅在社区要求验证时加载；
- **DNS 解析服务** —— 见下方「DNS 解析（DoH）」专节。

### DNS 解析（DoH）

为绕开 DNS 污染，本应用支持 DNS-over-HTTPS 加密解析。**该功能默认开启**，首次启动即生效。

解析请求会发送到下述 DNS 服务商（均为**社区第三方公益服务，开发者不运营、不控制**）：

| 服务商 | 地址 | 说明 |
|---|---|---|
| 社区 Edge 节点 | `https://edge.47258.xyz/linuxdo` | LINUX DO 社区提供的解析节点 |
| 社区公益 DoH | `https://jetdo.ddd.oaifree.com/query-dns` | LINUX DO 社区共享泛域名下的公共解析服务 |

关于这些请求，你需要知道：

- **发送的内容**：仅域名解析请求（待解析的主机名），不携带你的账号、Cookie、帖子内容或设备标识；
- **谁能看到**：对应服务的运营方能看到你查询的域名。它们是社区公益服务，**不在本应用开发者的控制范围内**，其隐私实践由其运营方负责；
- **你可以完全关闭**：「设置 → 网络与连接 → DoH 配置」中关闭「启用 DoH」后，应用不再向任何第三方 DNS 服务发送解析请求，全部走系统 DNS；
- **你可以换成自己的**：同一页面可添加你自己的 DoH 服务器地址，或在多个内置/自定义服务器之间切换。

除上述地址外，本应用不连接任何服务器，**也没有开发者自建的接收端**。

### 崩溃与日志

应用发生崩溃时，堆栈与相关日志**只写入本机**的应用私有目录，可在「设置 → 诊断日志」中查看、复制或导出。

**这些内容不会自动发送到任何地方**——只有你在自愿反馈问题时手动导出并发送，开发者才可能看到。是否导出、发给谁，完全由你决定。

### 登录与凭据

- 登录通过**系统 WebView 打开 LINUX DO 官方登录页**完成（含人机验证），本应用不接触、不存储你的账号密码；
- 登录成功后的会话 Cookie 由 Android 系统的 CookieManager 管理，**仅在你访问 linux.do 及其同源资源时回发**，不会发送给任何第三方域名。

### 上传内容

你在发帖/回帖中选择或拍摄的图片，经由 LINUX DO 官方上传接口传到社区（受社区规则约束）。拍照功能调用**系统相机应用**完成，本应用自身不做任何拍摄记录；扫码登录使用的 `CAMERA` 权限只用于在本地逐帧解码二维码，画面不上传、不留存。

## 三、权限使用说明

本应用申请的系统权限**仅以下 4 项**：

| 权限 | 用途 | 何时使用 |
|---|---|---|
| `INTERNET` | 访问 LINUX DO 社区 | 全程必需 |
| `ACCESS_NETWORK_STATE` | 检测网络连通性，提示离线状态 | 全程 |
| `POST_NOTIFICATIONS` | 推送新消息提醒 | 仅在你授权后；拒绝不影响核心功能 |
| `CAMERA` | 仅「扫码登录」扫描二维码时读取画面，逐帧在本地解码 | 仅在你进入扫码页并授权后；不做任何录制或留存 |

`CAMERA` 声明为**非必需**特性（`android:required="false"`），无摄像头设备也能正常安装使用。

本应用**不申请**：定位、通讯录、麦克风、存储、电话、传感器等任何其他敏感权限。拍照发图走**系统相机应用**（`ACTION_IMAGE_CAPTURE`），不需要 `CAMERA` 权限。

## 四、日志

应用内的调试日志（崩溃记录、请求日志）**只保存在设备本机**，在「设置 → 诊断日志」页面展示，供你自行查看与复制反馈。开发者没有任何远程收集渠道。

## 五、未成年人

本应用面向 LINUX DO 社区用户，不针对未成年人设计，不主动收集任何用户年龄信息。

## 六、你的权利

由于本应用不持有你的任何数据，你天然拥有完全控制权：

- **查看/删除本地数据**：卸载应用即可；
- **删除社区数据**：按 LINUX DO 社区规则在官网操作（本应用只是客户端）；
- **撤回授权**：系统设置中随时关闭通知权限。

## 七、政策更新

功能演进可能带来数据流变化，更新后将在应用发布说明中提示，并同步修改本文件的生效日期。
