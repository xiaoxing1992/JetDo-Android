# JetDo Android 隐私政策

> 生效日期：2026-10-03 ｜ 适用版本：1.0.1 及以上
>
> JetDo Android（以下简称"本应用"）是 LINUX DO 社区（https://linux.do）的**非官方**第三方客户端。我们非常重视你的隐私：本应用**不收集、不上传、不出售任何个人信息**，所有数据仅在你的设备与 LINUX DO 社区之间流转。请在使用前仔细阅读本政策。

## 一、我们收集什么

本应用不内置任何**广告或埋点统计** SDK；为定位崩溃问题接入了**腾讯 Bugly 崩溃上报 SDK**（详见下文「崩溃上报」）。除此之外应用本身不向开发者上传任何数据。

以下数据由你主动产生，**仅存储在你设备的应用私有目录中**，开发者无法读取：

| 数据 | 用途 | 存储位置 |
|---|---|---|
| 登录会话 Cookie | 维持你在 LINUX DO 的登录态 | 系统 WebView CookieManager（应用私有存储） |
| 本地偏好设置 | 主题、字体、开关项等 | 应用私有目录（DataStore） |
| 帖子草稿 | 未发送的回复/编辑内容 | 应用私有数据库 |
| 已读状态、书签缓存 | 离线展示与同步 | 应用私有数据库 |
| 图片/表情目录等缓存 | 加速加载、减少流量 | 应用私有缓存目录 |

**卸载应用即全部删除**上述本地数据。

## 二、数据流向哪里

本应用联网时，只与以下地址通信：

- **https://linux.do** —— 社区主站：浏览、登录、发帖、回帖、上传图片、实时消息等全部功能的数据来源；
- **https://cdn.ldstatic.com** —— LINUX DO 官方静态资源 CDN：图片、表情等站点资源；
- **腾讯 Bugly 崩溃上报服务**（`android.bugly.qq.com` / `report.bugly.qq.com`）—— 仅在崩溃/异常发生时上报（详见下文「崩溃上报」）；
- 你**自行配置**的 DNS-over-HTTPS 解析器 —— 仅发送 DNS 查询（域名解析请求），用于绕开 DNS 污染，不携带任何应用数据。

除此之外本应用不连接任何服务器。

### 崩溃上报（腾讯 Bugly）

应用发生崩溃（Java/Native 异常、ANR）时，会通过腾讯 Bugly SDK 加密上报以下信息，**仅用于定位和修复程序缺陷**：

- 崩溃发生时的堆栈与异常日志、应用版本；
- 设备型号、品牌、Android 系统版本与 API 等级、CPU 架构、设备是否 root；
- 磁盘/内存占用、网络类型等设备运行环境信息。

运营主体为深圳市腾讯计算机系统有限公司，其数据处理遵循《Bugly SDK 个人信息保护规则》（https://bugly.qq.com）。本应用不通过 Bugly 采集你的社区账号、浏览记录或任何内容数据。

### 登录与凭据

- 登录通过**系统 WebView 打开 LINUX DO 官方登录页**完成（含人机验证），本应用不接触、不存储你的账号密码；
- 登录成功后的会话 Cookie 由 Android 系统的 CookieManager 管理，**仅在你访问 linux.do 及其同源资源时回发**，不会发送给任何第三方域名。

### 上传内容

你在发帖/回帖中选择或拍摄的图片，经由 LINUX DO 官方上传接口传到社区（受社区规则约束）。拍照功能调用**系统相机应用**完成，本应用不申请相机权限、不做任何拍摄记录。

## 三、权限使用说明

本应用申请的系统权限**仅以下 3 项**：

| 权限 | 用途 | 何时使用 |
|---|---|---|
| `INTERNET` | 访问 LINUX DO 社区 | 全程必需 |
| `ACCESS_NETWORK_STATE` | 检测网络连通性，提示离线状态 | 全程 |
| `POST_NOTIFICATIONS` | 推送新消息提醒 | 仅在你授权后；拒绝不影响核心功能 |

本应用**不申请**：定位、通讯录、麦克风、相机、存储、电话、传感器等任何敏感权限。

## 四、日志

应用内的调试日志（崩溃记录、请求日志）保存在设备本机，在"日志"页面展示，供你自行查看与复制反馈；崩溃发生时的异常信息另经腾讯 Bugly 上报（见「崩溃上报」一节），开发者不通过其他任何远程渠道收集数据。

## 五、未成年人

本应用面向 LINUX DO 社区用户，不针对未成年人设计，不主动收集任何用户年龄信息。

## 六、你的权利

由于本应用不持有你的任何数据，你天然拥有完全控制权：

- **查看/删除本地数据**：卸载应用即可；
- **删除社区数据**：按 LINUX DO 社区规则在官网操作（本应用只是客户端）；
- **撤回授权**：系统设置中随时关闭通知权限。

## 七、政策更新

功能演进可能带来数据流变化，更新后将在应用发布说明中提示，并同步修改本文件的生效日期。
